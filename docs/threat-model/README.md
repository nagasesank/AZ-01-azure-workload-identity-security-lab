# Threat Model Documentation

- [Workload identity threat model](workload-identity-threat-model.md)

The threat model covers secret theft, credential replay, long-lived workload credentials, excessive Azure RBAC, authorization blast radius, trust boundaries, and negative controls. Federated identity and least privilege are planned mitigations; their validation has not started because Phase 4/5 work has not started.
